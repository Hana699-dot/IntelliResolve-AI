# VPN Connection Troubleshooting

1. Confirm that the device has an active internet connection.
2. Verify that the organisation-approved VPN client is running.
3. Note the exact error message and time of failure.
4. Restart the VPN client and retry once.
5. If the error continues, contact Network Support with the device name and error details.
6. Do not disable endpoint security or bypass corporate access controls.
