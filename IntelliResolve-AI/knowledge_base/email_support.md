# Email and Outlook Troubleshooting

1. Confirm that the internet connection is working.
2. Check whether the issue occurs in webmail as well as the desktop application.
3. Close and reopen the email application.
4. Check mailbox storage and any displayed service error.
5. If several employees are affected, report a possible shared mail service issue to Messaging Support.
6. Never send passwords or confidential email contents in a ticket unless an approved secure process requires it.
