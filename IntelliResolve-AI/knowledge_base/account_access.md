# Account, Password and Login Troubleshooting

1. Verify that the username is entered correctly.
2. Check whether Caps Lock or the keyboard language setting is affecting input.
3. Use the organisation's approved password reset portal.
4. If multi-factor authentication is failing, contact the Identity and Access team.
5. Never share passwords, one-time codes or recovery codes with support staff.
6. Escalate repeated account lockouts to the authorised identity team.
