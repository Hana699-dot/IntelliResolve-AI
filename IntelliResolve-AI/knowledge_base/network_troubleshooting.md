# Network and Wi-Fi Troubleshooting

1. Confirm Wi-Fi is enabled and airplane mode is disabled.
2. Check whether other websites or internal services are reachable.
3. Disconnect from the corporate Wi-Fi and reconnect using the approved company network.
4. Restart the device if permitted by company policy.
5. If multiple employees are affected, report the location, approximate start time and affected services to Network Support.
6. Do not share corporate passwords or authentication codes in a support ticket.
